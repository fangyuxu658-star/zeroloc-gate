# Contributing to ZeroLoc Gate

Read the [contribution guidelines](zeroloc-starter/CONTRIBUTING.md) and [current verification status](zeroloc-starter/STATUS.md).

Run npm commands from `zeroloc-starter/`. The actual GitHub Actions workflow and PR template are in this repository root's `.github/`. Keep beta changes focused on stabilization, report real positive and negative results, and preserve local-only defaults and third-party notices.

First-publication authentication and approval stages are documented in the [publication guide](zeroloc-starter/docs/FIRST_GITHUB_PUBLICATION_CN.md). No remote write or release is implied by a local test passing.
